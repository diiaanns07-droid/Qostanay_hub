# Adal: совместная проверка LIVE CV и Enforce на Windows

Это незаполненный ручной чеклист, не отчёт PASS. Используйте согласованную текущую сборку и явный `-Enforce`; SYNTHETIC, проверка только интерфейса или отдельный запуск помощника не подтверждают совместную работу.

SHA из запуска: ____ · Windows/build: ____ · дата: ____ · проверяющий: ____ · session_id: ____.
Оценки: PASS — наблюдаемое действие совпало; FAIL — не совпало; PARTIAL — только обнаружено/частично; NOT RUN — не проверялось. PIN, код класса, токены и несогласованные изображения в отчёт не включать.

## До включения экзамена

1. Заранее подготовить зависимости, текущий dist и модели. Выполнить `Start-Adal.ps1 -Role Standalone -Enforce -CheckOnly` либо Student с адресом PC1/кодом. CheckOnly не включает устройство/ограничения и не заменяет пункты ниже.
2. Запустить нужную роль с `-Enforce`. Записать SHA, собственный `ADAL_DESKTOP_PID` и показанный режим ENFORCE. Убедиться в доступе к операторскому PIN; не публиковать его. Для локальной репетиции разрешён явный `-DemoOperator`.
3. **Аварийный выход — Ctrl+Alt+Shift+F12** (при необходимости Fn). Резерв: Ctrl+Alt+Del → Диспетчер задач → только напечатанный PID Adal. Другие процессы не трогать. Держать эту инструкцию доступной вне экзаменационного экрана.
4. Включить **LIVE**, пройти согласие, проверку камеры/моделей/среды и калибровку. Записать реальные `blocked / detected_only / unverified`. Если обязательная проверка не пройдена, не объявлять готовность и не обходить её старым диагностическим флагом.
5. В короткой тестовой сессии проверить аварийный выход и восстановление клавиатуры. Только после этого начать новую сессию для таблицы. Перед ограничениями сохранить другую работу.

## Выход и восстановление

В новой короткой сессии повторить Ctrl+Alt+Shift+F12: ограничения должны отпуститься без ожидания сервера. Если нет — резервный выход через Ctrl+Alt+Del и собственный PID. После каждого пути проверить в обычном редакторе ввод `abc абв 123`, Ctrl+C/V, Alt+Tab и Win; убедиться, что камера отпущена и нет оставшегося помощника. Результат: ____.

Отдельно проверить закрытие окна и аварийное закрытие консоли запускателя; ожидается завершение только его дочернего дерева, не нормальная сдача экзамена. Результат: ____.

Ctrl+Alt+Del/UAC не считаются блокируемыми. Один ноутбук не подтверждает три ПК или сто камер. Для PC1+PC2+PC3 повторить по общей Wi-Fi/Ethernet-сети и записать результаты каждого ПК отдельно. Оставшиеся NOT RUN/PARTIAL и ошибки приложить к handoff без секретов; физические результаты не подменять автоматическими тестами.
