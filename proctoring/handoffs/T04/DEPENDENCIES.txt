R2 Protocol qorgau.class.v1 -> additive fields/messages T04 relies on (all optional for old peers):
    command (server->student):  issued_at, expires_at (UTC ISO), ttl_ms (time LEFT at this delivery), attempt
    ack (student->server):      code: unsupported|invalid|expired|duplicate|failed|busy (machine reason),
                                result: {locked, exam_state, policy_id, policy_version}, executed_at
    command_progress (NEW type, student->server): {command_id, state: "received"|"executing"}
                                (keeps the v1 rule "exactly one ack per command": progress is not an ack)
    hello.capabilities:         {commands:[kinds], modes:["url","app"], command_progress:bool,
                                 command_expiry:bool, site_timer_pause:bool}
                                absent = plain v1 client -> only start_exam/finish_exam/lock/unlock are offered
    command.kind "apply_policy" (NEW): payload {policy_id, version, name, mode, start_url, allowed_urls,
                                auth_domains, allowed_apps, instructions_ru, site_timer_control:"none"}
    welcome.exam:               + policy_id, version, start_url, auth_domains, site_timer_control
    allowed_urls grammar:       v1 says "шаблоны" without a grammar; T04 proposes
                                <scheme>://<host|*.domain>[:port]<path-prefix>* (policies.py, STUDENT_CLIENT.md §4)
    Exact client rules: handoffs/T04/STUDENT_CLIENT.md.
