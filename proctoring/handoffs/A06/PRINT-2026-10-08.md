# A06 print/content protection

Branch `codex/proctor-A06-print`, base `4bbe0b79d3a1a42c9f4c180ede605011d6da8f78`.
Scope: desktop/main + A06 handoff; no contract/backend/renderer changes.

Both built-in exam and ExamSurface website share the content guard. Ctrl+P/S/U, keyboard zoom,
reload and Shift+F10/context key now have explicit, distinct Russian detail.shortcut labels.
New main-owned sandbox preload blocks window.print, contextmenu, selectstart, dragstart and Ctrl+wheel
while the surface is in exam mode. Main validates a fixed operation-id allowlist and exact registered
webContents, throttles each operation to 2/s. It receives no selection, clipboard, page text or URL.
Remote content has only a narrow boolean __adalContentPolicy.blocked gate; no qorgau/auth/lock/audio
bridge, no Node or IPC object. The static preload source is bundled with main and materialized under
Electron userData/shell-preloads before session registration; build/package manifests need no changes.

Layered Chromium protection: CSP sandbox without allow-modals blocks print even from a fresh iframe;
before-mouse-event stops right-click and left-button dragging before any frame receives them;
zoom-changed/visual zoom limits cover Chromium zoom. Normal hover, scrolling, clicking and typing remain.
Dragging controls inside a website also cannot operate while this mouse restriction is active.
No restrictions on other Windows apps, no native enforce/hook or Windows setting changes for these checks.

`environment_blocked_action` is an IncidentRule, not an EnvironmentAction. Events therefore use existing
clipboard_blocked/devtools_blocked/navigation_blocked/new_window_blocked with enforcement=blocked;
fusion already feeds these into environment_blocked_action. Each payload carries a Russian operation
label in detail.shortcut and, for DOM operations, a distinct electron.content.<operation> mechanism.
The current A07 Operator list renders only generic ENV_ACTION labels; displaying detail.shortcut there
would require an out-of-scope renderer change. Exact labels are already in the observation/journal payload.

Self-test adds key_print/save/source/zoom/context_menu and page_print/context_menu/selection/drag/zoom.
Capability statuses depend on those outcomes (failed/unexercised mechanisms are not promoted to blocked).
Real Electron fixture verified all 22 self-test checks and 16 website scenarios, including allowed iframe
print and native mouse event cancellation, strict allowlist, popups, redirects, download, lock/pause cleanup.
This is a component test on the laptop with synthetic shell/class state: no backend session, camera,
microphone, kiosk, focus pulling, native helper or global shortcuts. It is not full classroom E2E.

Reproduce from proctoring/desktop: `npm run typecheck`, `npm run build:electron`, `npm run test:shell`,
`node main/tests/exam-surface.mjs`. Website video commands and actual network result follow in WEBSITE_DEMO.md.
