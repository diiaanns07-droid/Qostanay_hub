A08 -> A01 requests (contract qorgau.v1 1.0.0, baseline 35bea4c7b28d2c622cf7ba26ff354273cc7b6c49)

1. [integration, required] Two A01 tests assume proctor.evidence is NOT integrated and fail once it is:
   * backend/tests/test_lifecycle_api.py::test_health_reports_missing_modules_honestly
     expects health code "module_not_integrated" for evidence; with A08 it is "ok".
   * backend/tests/test_lifecycle_api.py::test_live_never_falls_back_to_synthetic
     expects preflight check "storage" = fail for LIVE; with A08 storage passes (camera/phone/face/fusion/
     environment_protection still fail, ready stays false - the LIVE guarantee is unchanged).
   Proposal: drop "evidence" from the loop / from the storage assertion, or parametrize on integrated modules.

2. [export completeness, medium] ExportManifest.models is empty: the store never sees ModelManifest objects nor
   IncidentEngine.config_snapshot(). Today config_versions are derived from incidents (rule/config_version) and
   observation producers (version, model_id, model_sha256). Proposal (no wire change): after creating the engine
   in SessionRuntime.start(), call an optional
       store.record_session_config(session_id, models: list[ModelManifest], engine_config: dict[str, Any])
   (A08 adds the method; A01 calls it via hasattr until the Protocol is extended), or expose models via
   BackendContext.

3. [delete consistency, low] DELETE /v1/sessions/{sid} removes everything in A08, but SessionManager keeps the
   terminal SessionRuntime in memory, so A01's GET /v1/sessions/{sid} still returns SessionInfo afterwards.
   Proposal: BackendContext.forget_session(session_id) (A01 drops a terminal runtime); the A08 router calls it
   after a successful delete.

4. [timing precision, low] SessionInfo has no session-time stamp for pause/resume/finish, so A08 derives those
   from wall clock at upsert_session(). Exact only for exam start (exam_started_t_ms). If precise pause gaps are
   needed: either a contract field (e.g. state_changed_t_ms) in v1.1, or an optional
   store.note_transition(session_id, state, t_session_ms) call from SessionRuntime._update().

5. [snapshots, info for A01/A05] capture_snapshot() is called only for OPENED changes with trigger_frame_id, and
   capture.get_frame() keeps ~settings.frame_ring_seconds (3 s). Rules that open after a long condition (gaze 5 s+)
   should set trigger_frame_id to a recent frame, otherwise there is no snapshot (metadata still kept).

6. [stream, info for A07/A01] IncidentMsg on /v1/stream carries A05's incident (review_status=pending,
   evidence_ids=[]). The UI must refetch REST. Optional: A01 publishes the store-overlaid incident instead.

7. [config, optional] A08 knobs live in EvidenceConfig with env overrides QORGAU_EVIDENCE_<FIELD>
   (media TTL, limits, coverage gap). If A01 prefers Settings fields, A08 will read them from Settings instead.

8. [dependency, info] JPEG snapshots use cv2 (opencv-contrib-python, `cv` extra). With runtime-only requirements
   (no cv2) snapshots are skipped (counter snapshot_encoder_unavailable), metadata is still stored. No new deps.
