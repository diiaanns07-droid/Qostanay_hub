  venv кандидата, локальные модели/записи, DEMO PIN, снятие `ELECTRON_RUN_AS_NODE` и старого dev URL.

  Конец определяется по реальному `HealthObservation` capture: `replay_ended`, а не по таймеру.
  Событие привязано к сессии и сбрасывается при её смене.
- Инструкция `REPLAY_VIDEO.md`: PIN до создания сессии; выбор точного replay ID;
  явный пропуск калибровки преподавателем; завершение сразу после конца записи; сохранение и открытие HTML.
  Автоматического открытия HTML после сохранения оболочка не предоставляет; новый IPC не добавлялся.

   сам ветки не переключает и pull не делает. Общий checkout A07 не изменял.
2. Для `proctoring/demo/` пользователь потребовал «по согласованию с A10».
   Скрипт и инструкция подготовлены в handoffs/A07; ожидается подтверждение размещения двух новых файлов в demo.
   Существующие материалы A10 не менялись.
3. REPLAY начинает идти при preflight. Не тратить время на ввод PIN после начала ролика.
   Долгое ожидание после конца создаёт реальный пробел наблюдения и может дать серую зону.
   Переключения окон/ограниченные клавиши при реальном Electron могут добавить события и изменить зону;
   результаты автоматического прогона относятся к записанным кадрам без таких действий.
4. Фактическая запись видео, ручной диалог сохранения, новый LIVE с камерой и нативное enforce в этом этапе **не проверялись**.
   Предыдущие подтверждённые капитаном LIVE PASS калибровки и A06 guard не переобозначаются как новые проверки.
5. A01/A08: в HTML этой базы остаётся старое видимое имя продукта (заголовок/подвал).
   Backend запрещён текущей задачей, поэтому A07 оставил только запрос владельцу.
