# Adal — запасное видео REPLAY

1. **Аварийный выход: Ctrl+Alt+Shift+F12.** Если оболочка не отвечает: Ctrl+Alt+Del → Диспетчер задач. Завершайте только процесс этого запуска Adal. После аварийного выхода проверьте ввод текста и переключение окон.
2. Капитан сначала вливает A07 и обновляет `verify-candidate` на получившуюся интеграцию. Скрипт запуска **не делает fetch/pull**: он собирает код, который уже находится в `verify-candidate`. Иначе нового отображения зон и конца REPLAY там ещё не будет.
3. Закройте предыдущий Adal штатно. В обычном PowerShell запустите из корня checkout с этим файлом:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\proctoring\handoffs\A07\Start-AdalDemo.ps1
   ```

   Сейчас скрипт размещён в handoffs/A07, перенос в `proctoring/demo/Start-AdalDemo.ps1` ожидает согласования A10. Для демонстрации нативного подавления клавиш добавьте `-Enforce`. Без него helper только фиксирует действия. Скрипт убирает `ELECTRON_RUN_AS_NODE`, задаёт локальные модели/записи, использует venv кандидата, пересобирает Electron и renderer существующими зависимостями, затем запускает Adal. Пакеты не устанавливает. После закрытия возвращает прежнее окружение консоли. `-CheckOnly` проверяет пути, не запускает приложение. Если checkout в другом месте, укажите `-CandidateRoot 'полный путь к verify-candidate'`.
4. До захвата видео прочитайте одноразовый PIN из строки `[Adal DEMO]` в консоли. Если настроен постоянный PIN, действует он. **Консоль с PIN в видео не показывайте.** В Adal заранее откройте «Режим преподавателя» и введите PIN — до запуска ролика.
5. «Подготовка к экзамену» → «Дополнительные настройки» → «запись (replay)» → «Идентификатор записи». Введите одно имя **без пути и без `.json`**:

   | Имя | Длина ролика | Зона в проверенном прогоне |
   |---|---:|---|
   | `zone_a_green_01` | 30 с | зелёная — без замечаний |
   | `zone_b_yellow_02` | 35 с | жёлтая — требует внимания |
   | `zone_c_red_01` | 40 с | красная — проверить в первую очередь |

   Файлы и manifest уже находятся в `%LOCALAPPDATA%\QorgauExam\replay`. Экзамен: `demo-exam-1`. Подтвердите ознакомление. На экране должна быть пометка **REPLAY**.
6. Заранее скопируйте причину: `REPLAY: записанное видео; пропуск калибровки преподавателем для демонстрации.` Нажмите «Проверить устройства», дождитесь готовности → «Без калибровки…» → вставьте причину → «Пропустить калибровку» → «Начать экзамен». Ролик начинает идти **при проверке устройств** и не перематывается при старте экзамена. Этот переход делайте сразу: первые события красного ролика начинаются на 4,5 с. Пропуск калибровки честно остаётся в отчёте; запись не демонстрирует индивидуальную калибровку взгляда.
7. Дайте один ответ, дождитесь «Сохранено». Оставайтесь в окне Adal: переключения окон и клавиши могут добавить настоящие события среды и изменить зону. При сообщении **«REPLAY — запись закончилась»** сразу нажмите «Завершить экзамен» → «Завершить». Не оставляйте экзамен надолго без кадров: это уменьшает покрытие наблюдением.
8. «Режим преподавателя…» → PIN → «К итогу →». Покажите пометку REPLAY, название зоны и её причины. «Сохранить отчёт HTML» → выберите папку в системном диалоге → дождитесь «Файл записан». Откройте сохранённый `.html` двойным щелчком в Проводнике. **Автоматического открытия после сохранения сейчас нет.** В отчёте видны REPLAY, та же зона и эпизоды. Затем «Новая сессия» и следующая запись.

Зона определяет порядок проверки преподавателем. Она зависит от фактически обработанных кадров и событий, поэтому при другом результате показывайте реальное значение. Для повторения создайте новую сессию с тем же именем записи.

Проверка A07: настоящий backend/CV стабильной базы `e3ee57bb9f0dac544129f809af3911da9520ce7a` (включает `eee2031`), продуктовый renderer и main API. UI проверен через Chromium с тестовым транспортом и без системного guard; системный диалог сохранения заменён записью настоящего HTML в тестовую папку. Реальная запись видео, нативное подавление и ручной диалог сохранения этим прогоном не проверены. Подробности: `handoffs/A07/DEMO_VIDEO.md`.

Для A01/A08: заголовок экспортируемого HTML в этой базе ещё содержит старое имя продукта. Исправление находится вне разрешённых для этой задачи путей; backend A07 не менял.
