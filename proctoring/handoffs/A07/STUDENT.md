## 1. Калибровка на весь экран (push 1)
* `screens/Calibration.tsx`: фаза сбора — полноэкранный слой `.calfs` поверх всего окна; пять крупных точек у краёв
  экрана в порядке A04/A01 (`CalibrationTargetValues`: центр → влево → вправо → вверх → вниз), отступ 44 px от края.
  Активная точка 46 px, пульсирует, кольцо прогресса = `samples / required_samples` от backend (не таймер).
  Собранная точка — зелёная с «✓», несобранная — красная, плюс текст в панели («собрано ✓ / не собрано / ждёт»,
  причина «Точка «вверх» не собрана: …»): цвет всегда с текстом.
* Подсказка крупно: «Смотрите на точку глазами, голову держите прямо.»
* Вступление: точки не запрашиваются, пока студент не нажал «Начать калибровку». Нажатие (жест) разворачивает окно
  на весь экран и запускает автосбор. Уже начатая калибровка (перезагрузка окна) продолжается без вступления.
* Панель статуса — между верхней и центральной точкой, кнопки — между центральной и нижней; проверено, что они не
  перекрывают ни одну точку на 1366×768 и 1920×1080. После калибровки окно выходит из полного экрана
  (режим экзамена A06 потом включает свой полный экран сам).

## 2–3. Экран блокировки и индикатор микрофона (push 2)
* Источник: сообщение `class_state` (C2, `handoffs/C2/STATUS.md`) из существующего WS `/v1/stream`; main A06
  пересылает его без изменений (проверяется только конверт). Разбор — `lib/classState.ts` (защитный: битое
  сообщение игнорируется), состояние — `LiveStore.classState` (не привязано к сессии, `reset()` его не сбрасывает).
* `locked=true` → `components/ClassOverlays.tsx` `LockScreen`: непрозрачный слой на всё окно поверх экзамена и
  калибровки (z-index 1000), «Преподаватель приостановил ваш экзамен», «Причина: …» (`lock_reason_ru`), пояснение,
  что камера и наблюдение продолжают работать. Кнопок нет; приложение под слоем `inert` + фокус удерживается в слое
  (Escape/Tab не выводят). `unlock` (`locked=false`) снимает слой. Камеру/наблюдение renderer не трогает.
* `mic_active=true` → `MicBanner`: красная плашка сверху на всю ширину, «Микрофон включён преподавателем для
  проверки» (+ «преподаватель говорит с вами» / «двусторонняя связь» по `audio_direction`), видна и поверх экрана
  блокировки (z-index 1100); кнопки скрытия нет; содержимое сдвигается вниз (`.app-mic`), шапка не перекрыта.
  Сам микрофон renderer НЕ включает (WebRTC — п. 5, не сделан).

## 4. Блок «Класс» на экране подготовки (push 3)
* `ClassBlock` в правой колонке экрана подготовки: связь текстом + цветной меткой (подключено / подключение… /
  переподключение: сервер класса не отвечает / неверный код подключения / связь с классом остановлена), сервер,
  компьютер, номер у преподавателя, название экзамена, `message_ru` от uplink. Без данных: «Состояние подключения к
  классу ещё не получено…» (экзамен локально — это нормально).
* Полей ввода адреса/кода нет: у C2 нет метода задать их во время работы (uplink настраивается переменными
  `QORGAU_CLASS_SERVER` / `QORGAU_CLASS_CODE` при запуске backend) — запрос ниже.
