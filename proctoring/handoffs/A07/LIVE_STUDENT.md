# Оставшаяся LIVE-проверка взгляда вниз

**Выход:** в экзамене Ctrl+Alt+Shift+F12; до экзамена — закрыть окно. Нативный перехват клавиш в этом QA-запуске отключён.
Используется настоящая камера и backend текущей рабочей копии. Соединение с классом отключено только для
этого процесса. Настройки Windows не меняются; другие экземпляры приложения не закрываются.

На этом ноутбуке из любой папки (сборка, Python и модели уже подготовлены):

```powershell
node C:\Qostanay_hub-codex-proctoring-prompts\worktrees\A07-student\proctoring\desktop\renderer\tests\start-live.mjs
```

1. «Камера (live)» → ознакомление → «Создать сессию и проверить». Если камера занята, завершите её использование
   в другом приложении сами; скрипт чужие процессы не трогает.
2. «К калибровке» → «Начать калибровку». Смотрите на точки глазами, держите голову прямо. При ошибке повторите точку.
   В текущем обновлении A01 только «вверх» необязательна: если она не собрана, интерфейс позволяет завершить
   калибровку после остальных точек. Запишите, удалось ли собрать «вверх» или использовано это исключение.
3. «Завершить калибровку» → «Начать экзамен». 10–20 секунд смотрите на экран.
4. Посмотрите вниз на клавиатуру/колени на 4–5 секунд, затем 10 секунд снова на экран.
5. «Завершить экзамен» → «Завершить». Сообщите, удалось ли пройти все точки и выполнить взгляд вниз.

Тест использует отдельный профиль и каталог `%LOCALAPPDATA%\QorgauExam\A07-live\<время>`.
Путь последнего запуска — в `A07-live/latest.json`. `observed.json` содержит состояние калибровки и реальные
события эпизодов; `calibration-*.png` — снимки полноэкранного UI, без показа видеопредпросмотра.
Лицо, landmarks, набранные ответы и буфер обмена QA-скрипт не сохраняет.
Наличие эпизода и совпадение с сообщённым действием проверяются отдельно: скрипт не выставляет PASS автоматически.
Приложение закрывается штатно; оболочка сама завершает свой backend.
