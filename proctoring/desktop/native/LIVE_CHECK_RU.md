# Контролируемая проверка qorgau-guard на Windows

**Сначала выход:** Ctrl+Alt+Shift+F12 снимает хук и завершает helper. Другие варианты:
закрыть окно тестовой консоли; Ctrl+Alt+Del → Диспетчер задач → завершить только
helper с PID, который напечатан в консоли. Лимит каждого запуска — 2 минуты.
После любого выхода проверить обычный ввод, Win, Alt+Tab и фокус другого приложения.

Запускать только после явного «да» капитана в чате. Оба режима ставят настоящий хук;
dry-run лишь фиксирует выбранные клавиши, enforce их подавляет. Ctrl+Alt+Del и UAC
не блокируются. Python-прототип не подписан. Проверка не меняет настройки Windows.

Команда из `proctoring/` (существующий Python кандидата; новая папка результата для каждого запуска):

```powershell
& '<python-кандидата.exe>' desktop/native/live_console.py --mode dry-run --out '<новая-папка-dry>'
# Только после завершения dry-run и готовности капитана:
& '<python-кандидата.exe>' desktop/native/live_console.py --mode enforce --out '<новая-папка-enforce>'
```

1. Дождаться `ready`, `hook:true` и нужного `mode`.
2. **dry-run:** Win, Alt+Tab, PrtScn работают как обычно. В консоли соответствующие
   `key` имеют `swallowed:false`. Стороннее окно даёт `foreground`, только basename процесса.
3. Напечатать `stop` и Enter. Дождаться `bye:stop_requested` и `HELPER EXITED`.
4. Проверить ввод текста, Win/Alt+Tab и фокус после выхода.
5. **enforce:** те же три клавиши не выполняют системное действие;
   соответствующие события имеют `swallowed:true`. Дополнительно проверить Alt+Esc и Ctrl+Esc.
6. Ctrl+Alt+Shift+F12 должен дать `bye:emergency_hotkey` и `HELPER EXITED`.
   Проверить ввод, Win/Alt+Tab и фокус после выхода. При необходимости отдельно повторить с `stop`.
7. Сообщить результаты каждого пункта: PASS / FAIL / PARTIAL и что произошло.

Консоль автоматически посылает heartbeat. `events.jsonl` содержит только фиксированные
события протокола; `machine.json` — точную платформу и выпуск ОС. Эти файлы сами по себе
не доказывают подавление клавиш. `VERIFICATION.json` заполняется по реальному тесту и
сообщённым наблюдениям; не проверенные действия не получают запись `blocked`.
