# Установка Adal на ПК с Windows — инструкция для ИТ-специалиста

Adal ставится из исходников репозитория одной командой `packaging\Install-Adal.ps1`. Скрипт работает без прав администратора и не ставит системные программы: он их только проверяет и печатает ссылки. Реестр, службы, автозагрузку, брандмауэр и постоянную ExecutionPolicy он не меняет. Внутри он вызывает существующую подготовку `prepare-windows.ps1 -FetchModels`, проверяет модели и запуск (`Start-Adal.ps1 -CheckOnly`) и создаёт ярлыки текущего пользователя в меню «Пуск» (папка Adal) и на рабочем столе.

## Что нужно заранее

Windows 10/11 x64, учётная запись, под которой будут работать с Adal (права администратора не нужны), не меньше 3 ГБ свободного места (проект после установки занимает около 0,8 ГБ, плюс кэши uv, npm и Electron). Интернет нужен один раз, на шаге 4.

| Программа | Ссылка | Или winget |
| --- | --- | --- |
| Python 3.12 x64 | [python-3.12.10-amd64.exe](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe) ([страница выпуска](https://www.python.org/downloads/release/python-31210/)) | `winget install -e --id Python.Python.3.12` |
| uv | [docs.astral.sh/uv](https://docs.astral.sh/uv/getting-started/installation/) | `winget install -e --id astral-sh.uv` |
| Node.js LTS ≥ 22.12 (с npm) | [nodejs.org/en/download](https://nodejs.org/en/download) | `winget install -e --id OpenJS.NodeJS.LTS` |
| Git | [git-scm.com/downloads/win](https://git-scm.com/downloads/win) | `winget install -e --id Git.Git` |

## Шаги

1. **Установите программы из таблицы**, затем закройте и снова откройте PowerShell, чтобы обновился PATH.
2. **Склонируйте репозиторий** в короткий путь без кириллицы и не переносите папку после установки (окружение и ярлыки привязаны к пути):
   ```powershell
   git clone --branch main https://github.com/diiaanns07-droid/Qostanay_hub.git C:\Adal
   cd C:\Adal\proctoring
   ```
3. **Пробный запуск** — ничего не скачивает и не меняет, показывает план:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\packaging\Install-Adal.ps1 -CheckOnly
   ```
   Код 0 — требования выполнены. Код 2 — чего-то не хватает, ссылки напечатаны в выводе.
4. **Установка** (нужен интернет, первый раз 5–15 минут):
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\packaging\Install-Adal.ps1
   # На студенческих ПК можно сразу вписать адрес ПК преподавателя в ярлык:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\packaging\Install-Adal.ps1 -Server 192.168.1.10:8765
   ```
   Скачиваются: Python-пакеты по `uv.lock`, npm-пакеты по `package-lock.json` и Electron 43.7.5 (около 150 МБ), модели YOLO11n (10,9 МБ) и MediaPipe FaceLandmarker (3,8 МБ) — с проверкой размера и SHA256. Дальше запуск и экзамен интернет не используют. Повторный запуск безопасен: если всё готово, подготовка пропускается (`-Force` — повторить её). `-NoShortcuts` — без ярлыков.
5. **Проверка**: ярлык «Adal — проверка (CheckOnly)» проверяет роли преподавателя и студента без окна, камеры, микрофона, сети и hooks.
6. **ПК преподавателя**: ярлык «Adal — преподаватель (класс)». Откройте `http://127.0.0.1:8765/`, введите PIN из консоли и создайте класс. Студентам сообщите LAN-адрес из консоли (например, `192.168.1.10:8765`) и шестизначный код класса. Консоль не закрывайте. Чтобы студенты могли подключиться, разрешите входящий TCP-порт 8765 в частном профиле брандмауэра — вручную, в PowerShell от администратора (скрипты Adal брандмауэр не меняют):
   ```powershell
   New-NetFirewallRule -DisplayName 'Adal класс TCP 8765' -Direction Inbound -Protocol TCP -LocalPort 8765 -Profile Private -Action Allow
   ```
7. **ПК студента**: ярлык «Adal — студент» спросит адрес ПК преподавателя (если он не вписан через `-Server`) и код класса. В Adal выберите LIVE, пройдите согласие, проверку оборудования и калибровку. Ярлык запускает экзамен с `-Enforce`: ограничения системных клавиш включаются только во время сессии экзамена.
8. **Удалённый доступ и экран.** Пока работает RustDesk, AnyDesk, TeamViewer, UltraViewer, Chrome Remote Desktop (`remoting_host`), Parsec, VNC (`winvnc`, `tvnserver`) или RMS (`rutserv`), в том числе как служба, Adal не начнёт экзамен и покажет «Закройте rustdesk.exe, чтобы начать». В RDP-сеансе и со вторым монитором экзамен тоже не стартует. Adal сам ничего не закрывает: остановите эти программы и их службы на время экзамена и включите после него. Установку через RustDesk выполнять можно: проверка срабатывает при старте экзамена, а установщик только предупреждает.
9. **Аварийный выход: Ctrl+Alt+Shift+F12** (на некоторых ноутбуках вместе с Fn). Проверьте его на каждом ПК в короткой пробной сессии. Если Adal завис: Ctrl+Alt+Del → Диспетчер задач → завершите только процесс с `ADAL_DESKTOP_PID` из консоли запуска, не все `electron.exe`. Затем проверьте клавиатуру, Alt+Tab и Win.
10. **Обновление и удаление.** Обновление: `git pull`, затем шаг 4. `-Uninstall` удаляет только ярлыки, созданные установщиком (`-Uninstall -CheckOnly` покажет список). Папку проекта и данные экзаменов (`%LOCALAPPDATA%\QorgauExam`, `%LOCALAPPDATA%\QorgauClassroom`) удаляйте вручную по правилам хранения данных вуза.

## Ограничения

- Это установка из исходников, а не подписанный MSI/EXE. Если ExecutionPolicy задана групповой политикой (например, AllSigned), `-ExecutionPolicy Bypass` не действует — запуск нужно согласовать.
- Ярлыки создаются для текущего пользователя. Для другой учётной записи выполните шаг 4 под ней: если папка уже подготовлена, подготовка будет пропущена.
- Проверки установщика подтверждают файлы, зависимости, сборку и SHA256 моделей. Камеру, микрофон, сеть класса и блокировку Windows они не подтверждают — их проверяют вручную по [LIVE-чеклисту](../qa/scenarios/LIVE_TONIGHT.md). Совместная работа на трёх физических ПК пока не подтверждена.
- Ctrl+Alt+Del и экран UAC не блокируются. Сигналы Adal — наблюдения для проверки преподавателем, а не доказательство нарушения.
- YOLO11n распространяется по AGPL-3.0: перед распространением за пределами пилота проверьте условия лицензии.
- Класс без интернета на месте: заранее подготовьте офлайн-комплект (`python acceptance\offline\adal_offline_kit.py plan`).

Подробнее о ролях, Enforce и восстановлении — в [README](../README.md).
